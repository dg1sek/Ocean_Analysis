# bivalve_test: shell chronology (Arctica islandica, North Icelandic Shelf) as a test of the 65-80 yr line (28 Nov 2026)
Runs from this folder: `Rscript 95_bivalve.R`. Data included (Butler et al. 2013, NOAA NCEI). The ERSST file (`data/ersst.v6.sst.mnmean.nc`, download script in `regional_test`) is needed only for the SST comparison B3.
Design: PREREG_bivalve.md. Results: RESULTS_bivalve.md.
